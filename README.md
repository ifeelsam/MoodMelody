# Project: Mood Melody

*A web app that can play music based on the user’s mood: We will use .NET framework to create a web app that can analyze the user’s mood from their facial expressions or voice and play music accordingly. Using existing libraries and APIs to help us with the mood analysis and music recommendation, such as OpenCV or Spotify.*
## Used Packages and Modules

- [OpenCV](https://www.geeksforgeeks.org/opencv-python-tutorial/): OpenCV is a Python open-source package used for computer vision, machine learning, and image processing.
- [Matplotlib:](https://www.geeksforgeeks.org/python-introduction-matplotlib/) Python’s Matplotlib module is a complete tool for building static, animated, and interactive visualizations.
- [Deepface](https://www.geeksforgeeks.org/facial-expression-detection-using-deepface-module-in-python/): A Facebook research team specializing in artificial intelligence developed Deepface. [Python](https://www.geeksforgeeks.org/python-programming-language/) provides a framework for analyzing properties and recognizing faces. Keras and [TensorFlow](https://www.geeksforgeeks.org/introduction-to-tensorflow/) both utilize key library elements from Deepface.
- [Requests](https://www.geeksforgeeks.org/python-requests-tutorial/): Sending HTTP/1.1 requests is incredibly simple with Requests. These days, all you have to do is use the [JSON](https://www.geeksforgeeks.org/javascript-json/) method instead of manually adding query strings to your URLs or form-encoding your PUT and POST data.
